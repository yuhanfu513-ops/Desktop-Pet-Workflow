# 音频处理与台词编辑

## 提取与切句

- 先检查源文件时长、音轨和采样率；MP4/MOV 只提取音频，保留原文件。macOS 可用 AVFoundation 导出 M4A，再用 `afconvert` 解码成 PCM WAV；用于识别的 16 kHz 单声道与用于最终播放的较高采样率音频分开。
- 根据完整语义和实际停顿划分，而不是只按固定秒数。语音识别可给出候选边界和字幕，但口音、背景音乐和专有词经常出错；结合原音频和视频原字幕校对。源视频本身截断的字句不能补造。录音里多人时，不凭声音或图片猜身份；用用户确认的先后/对应关系区分。
- 输出单独的无损小片段，并记录来源、起止时间、文字和实际时长。切点保留必要的句首尾，必要时使用几毫秒淡入淡出，避免爆音；相邻句混有其他说话人时不要盲目重叠。保留可回溯的裁切清单。
- 可用本技能的 `scripts/cut_clips.py`：输入是 16 位 PCM WAV 的 JSON 清单，输出到**不存在的新目录**，包含 `clips.json` 和 `Clips/*.wav`。它不覆盖已有输出，不自动上传或修改原音频。示例：

  ```json
  [{"source":"speech.wav","start":0.2,"end":2.6,"label":"这一句的文字"}]
  ```

  `python3 scripts/cut_clips.py cuts.json --output /tmp/pet-clips`。其中 `scripts/` 相对于技能目录；在项目目录运行时改用脚本的绝对路径。输入音频路径相对清单所在目录；`--fade-ms` 控制淡入淡出。需要和现有桌宠听感接近时，先测量并试听，再考虑 `--target-rms 0.1`（约 -20 dBFS，附峰值限制）；这是可选处理，不保证感知响度完全一致。
- 裁切记录包含本机源文件路径；对外发布前检查并移除不应公开的本机路径。将生成的清单和音频一起放入项目预期路径；检查清单 ID、文件、时长、字幕及随机池一致。对长字幕检查最小/默认尺寸，避免截字。

## 删除、合并和替换

- 截图里的序号可能来自旧版本，先按文字及来源时间确认具体片段。删除指定句只影响该句；其他相似句、原始视频和用户设置不应被顺带删除。
- 合并同一录音中相邻两句时，从原音频重新裁取覆盖两句的连续区间，避免简单拼接造成重复、停顿或爆音；字幕和选句菜单同时更新。重新生成后检查实际音频包含两句，且不会再分别随机抽到它们。
- 如果重新编号，要同步清单、菜单和文件；在新的干净构建目录生成应用，确保旧片段不再打包。保留有用的裁切记录；不把临时缓存或旧安装包误当成当前版本。
